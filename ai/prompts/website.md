# Northweb Website — AI Design Prompt

Read:
- `/design-system/DESIGN-SYSTEM.md`
- `/design-system/tokens.json`

Design a premium, modern, editorial website for Northweb Studio.

Services:
- Websites
- E-commerce
- CRM & Systems
- Web Applications

Use the Northweb tokens exactly. Primary orange is `#F26522`; secondary green is `#4CAF50`; charcoal is `#2F3E46`. Use Inter for UI/body and Merriweather selectively for display headlines.

The brand should feel like an expert independent digital studio, not a generic marketing agency.

Prioritize strong typography, generous whitespace, clear hierarchy, accessibility, performance, responsive behavior, subtle motion, and high-quality visual composition.

Avoid excessive gradients, glassmorphism, neon colors, excessive rounded cards, generic SaaS layouts, and stock-photo clichés.
