# Northweb Studio

Digital studio focused on websites, e-commerce, CRM/business systems, and web applications.

## Repository

- `design-system/` — brand rules, tokens, and approved logo assets.
- `site/` — production Astro + Tailwind website.
- `source-files/` — editable/original design and brand files.
- `ai/` — reusable prompts and AI project guidance.

## Source of truth

Before making visual or UX decisions, read:
1. `design-system/DESIGN-SYSTEM.md`
2. `design-system/tokens.json`
3. `CLAUDE.md`

Northweb is positioned as a digital studio, not primarily as a social-media marketing agency.
